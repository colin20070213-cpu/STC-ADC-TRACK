# 单编码器速度闭环：PWM 指令加速度修正

## 菜单和指令

主菜单 → 电机设置 → 速度设定，只保留一组 BASE/CURVE，默认 2500/1400。两者现在都是 PWM 刻度指令：2500 提供 25% 的基础占空比；速度 PID 可在其上增加或减小动力，最终输出仍限制在 0～4000（40%）。BASE 不是最终 PWM 上限。

范围 0≤CURVE≤BASE≤4000，BASE=0 禁止发车。上下选择、右键编辑及切换 10/100 步长、中键保存、左键撤销/返回。页面 BASE/CURVE/NOW 均按 PWM 指令刻度显示；NOW 是编码器换算值，不是实际输出占空比。静态设置和速度 PID 调参页关闭电机及舵机。

## 参考系数和计算

按用户要求使用此前参考程序的关系：

```text
参考目标计数/20ms = PWM 指令 × 0.104
本程序目标计数/10ms = PWM 指令 × 0.052
实测计数/10ms = 本次新增脉冲 × 10 / 实际间隔ms
速度误差 = 目标计数/10ms − 滤波实测计数/10ms
最终 PWM = 限幅(指令 + Kp×误差 + I修正 + D修正，0～4000)
屏幕/串口反馈 = 滤波实测计数/10ms ÷ 0.052，四舍五入为整数
```

例如指令 2500 对应 260 计数/20ms、130 计数/10ms、平均26计数/2ms。实测正好满足该关系时，误差为零；没有历史积分、D分量为零时，最终 PWM 就是2500。低于目标补动力，高于目标减动力。

系数在 USER/inc/track_config.h：TRACK_ENCODER_REFERENCE_GAIN_X1000=104 表示0.104，TRACK_ENCODER_REFERENCE_PERIOD_MS=20 表示参考时间窗。ADC/编码器快照仍1ms，速度和转向 PID 仍2ms，不会为了使用20ms系数把控制周期改成20ms。内部保留原来的计数/10ms误差尺度，现有PID参数不自动缩放或重置；增加前馈、更改目标映射后仍需实车重新整定。

来源是上次读取的参考程序：约第436行 encoder_error=Input_PWM*0.104-actual_speed，第446行 actual_pwm=Input_PWM+Kp*error+Ki*integral；当时读取记录显示测速20ms。此次原文件 C:/Users/colinlee/Desktop/参考程序.txt 已不存在，按先前记录接入，未声称重新读取了原文件。0.104 是参考车经验值，尚未在本车实测。

## PID 与起步

测量反馈使用10ms时间常数的低通，测量微分使用30ms时间常数的低通；I按实际秒数积分。积分修正可正可负，并有上下界和抗饱和，以便基础动力过大时减小动力。

目标和 PWM 没有慢爬升，下一次有效2ms更新直接使用新的目标和有界输出。实际PWM由基础指令和PID修正共同决定，不能承诺设2500就始终输出2500。

PID调参 → 速度闭环调参，三档0.01/0.10/1.00、断电保存及第四项恢复宏初值保留。此次保留用户当前本地速度宏50/0/0、转向宏125/0/6.75及C4宏1/1.5/1；有效Flash参数仍优先。

## 保护与参数兼容

- 右后轮一个反馈，左右电机使用相同PWM，禁止差速命令。
- 弱信号确认期间只降不升，最大600 PWM，清空速度控制历史，避免积分顶开限速。
- 保留普通弱信号250ms、四路近零120ms、ADC保护、20ms输出更新截止、手动停车。
- 1ms计数快照失败锁存到前台；快照超过2ms、测速间隔超过4ms或异常计数时停止。
- PWM≥1000且连续约1000ms无脉冲时ENC STALL停车。P52显示原始电平，不声明AB四倍频或反向测速。
- 仍使用两个512B扇区，用户EEPROM至少1KB；SPD2总长80B、基础第31字节最后提交。offset20/22保留原BASE/CURVE数字，解释为PWM刻度指令；原独立目标offset40/42仅为兼容，不参与控制。
- 新保存写入PWM1单位标记，兼容旧PPS1、无标记SPD2、SPD1及v1/v2，不自动擦写、不清除原PID、舵机、方向或C4。旧2500/1400沿用，不再解释为2500/1400pps。

## 蓝牙与代码位置

115200/8N1，仍只发四列CSV：转向目标×1000、转向反馈×1000、速度指令、速度反馈（PWM指令刻度）。例如0,50,2500,2300，后两列可直接比较；第四列是编码器换算的实际轮速，不是最终PWM。

组帧和发送入口在 USER/src/track_app.c 的 telemetry_task()，转换在 USER/src/track_speed.c 的 TrackSpeed_FeedbackCommand()，发送队列和逐字节中断在 USER/src/track_hw.c 的 TrackUART_Queue()/TrackUART_TxISR()。

仅运行、转向PID调参和速度PID调参模式发送；无表头、无其他列。上一帧末字节发完再生成最新帧，不排队旧数据。参数页电机关闭，所以速度目标通常显示0；调参后开始运行再观察闭环波形。
