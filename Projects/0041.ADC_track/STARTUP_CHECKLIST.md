# 开始运行前检查与操作清单

本清单对应更换正常电磁放大板后的四电感固件。按键：上 P42、下 P46、左 P45、右 P41、中 P27；中键确认，左键返回或撤销。

## 一、首次烧录、修改硬件或调整参数后

1. 烧录 `MDK/Objects/Project_Template.hex`。STC-ISP 芯片选择 STC32G12K128，用户 EEPROM 至少分配 1KB，当前程序布局不要超过 64KB。希望后续重新烧录仍保留参数时，关闭下载器的擦除用户 EEPROM 选项。
2. 确认赛道电磁线正常通电；电感安装牢固，高度与实际运行一致。当前左横电感 P13、右横电感 P01。先在 track_config.h 填对左右纵电感的实际 ADC 引脚；当前配置为 P10/P05，请以实际接线核对。四路放大输出都必须正确接入。
3. 在“舵机设置”核对中值、左右限位、方向。当前代码默认中值 760、左限位 840、右限位 670；已有有效 EEPROM 参数优先。三个位置页面进入即输出对应舵机位置，电机关闭。方向设为反向时左右数值标签交换。
4. 在“电机设置”先设置目标速度 BASE/CURVE（P04 计数/10ms，初值 0，需非零 BASE），保存后核对速度 PID、左右电机方向及动力限幅。右后轮 P04/P52 按原库使用，可在静态速度页面手转检查反馈。动力限幅代码初值 BASE=3000（30%）、CURVE=1500（15%），必须满足 `0 ≤ CURVE ≤ BASE ≤ 4000`。提高上限不会自动提高已保存动力，需要在动力限幅页调整并中键保存。方向设置页不会让电机试转；需完成下文标定后架空短时运行，验证两轮前进方向，左键或中键停止，再根据结果调整方向。
5. 核对 PID 页的实际参数。代码当前初值 Kp=130.00、Ki=0.00、Kd=8.15，允许范围分别为 0～500、0～20、0～20。已有有效 EEPROM 参数仍优先；需要使用代码初值时，选择“恢复PID初值”，第一次中键预览，第二次中键保存，确认 `SAVED OK`。
6. 修改任一需要掉电保存的设置后，按中键确认，看到 `SAVED OK`。失败时按屏幕错误阶段排查，不能将预览数值当作已掉电保存的值。

## 二、每次上电后必须按顺序执行

### 1. 电感标定

- 进入“标定设置 → 电感标定”，进入即开始采集。
- 保持安装高度不变，手动移动小车，使全部四个电感都经历弱信号和强信号位置，观察 `N/m/M`。
- 每路采样至少 250 帧（2ms/帧，至少约 0.5 秒），每路 `M-m ≥ 100`，且 `M < 4090`；实际应充分扫过信号范围，不能只等待采样计数增加。
- 按中键校验并确认；成功后自动回到标定菜单。左键退出为取消，右键清空重新采集。

### 2. 车身居中标定

- 将小车放到直线赛道中央，车身纵向对齐赛道，保持静止，进入“标定设置 → 居中标定”。
- 按中键开始采集 500 帧，约 1 秒；此时电机及舵机输出关闭。
- 归一化 L/R 每路至少为 100，总和不低于失线阈值（当前代码默认 40）；E 绝对值不超过 300，整次采集 E 的最大值与最小值之差不超过 60。
- 显示 `READY: OK TO SAVE` 后，再按中键，看到 `CENTER SAVED (RAM)`，然后按左键返回菜单。
- `SIGNAL TOO WEAK` 为信号强度不足；`UNSTABLE: RETRY` 为采集期间波动过大；`OFF CENTER: REALIGN` 为偏差过大。调整摆放或信号后重新采集，失败不会生成新的有效居中参考。

### 3. 核对转向并选择开始运行

- 首次整定或改过方向时，在 PID 调参模式下观察电感偏差与舵机响应，确认舵机向使车身回归赛道的方向纠偏；该模式电机始终关闭。
- 确认速度、机械限位及电机方向合适后，将小车放在有效赛道信号范围内，主菜单选择“开始运行”，按中键发车。通过检查后屏幕熄灭且停止刷新；失线或手动停车后重新亮屏显示原因。
- 运行中左键或中键立即停止。弱信号确认期间保持原转向，动力不超过原值、CURVE、600 的最小值；普通弱信号约 250ms、四路连续近零约 120ms 后停车。运行门槛取 min(保存值,20)，通常总和恢复到 30 时可在确认期内恢复循迹。ADC 故障或控制超时仍直接停止；已经停车后需手动再次发车。

## 三、发车提示对应什么前置条件

| 提示 | 含义与操作 |
|---|---|
| NEED SPEED | 速度目标为 0，先在电机设置→速度设定设置非零 BASE 并保存 |
| ENC ERROR | 编码器快照或计数/间隔异常，检查右后轮信号 |
| ENC STALL | 有持续动力而无脉冲，检查堵转、编码器连接及调参 |
| NEED CAL | 本次上电尚未成功确认电感标定，先完成第 1 步 |
| NEED CENTER / NEED CENT | 尚未成功确认居中参考，先完成第 2 步 |
| PARAM ERR / FLASH PARAM ERROR | 控制参数不合法；保存会检查整套参数。核对 PID、舵机、动力关系及方向；失线总强度合法范围为 1～500，当前初值 40 可正常保存 |
| MATH ERROR | 上电整数计算自检失败，先排查固件及运行环境 |
| LOST | 弱信号持续约 250ms，或四路连续近零约 120ms，已停车；重新摆放到有效赛道信号区域后再启动 |

先前一处 `PARAM ERR` 原因是 Kp=400.00 超过当时允许上限 200.00。当前上限为 500.00，代码初值为用户当前设置的 130.00；上电会检查参数，有效 EEPROM 记录仍优先。

电感极值和车身居中参考只存在 RAM：每次断电重启均须重新完成两项标定。成功重做电感标定也会使旧居中参考失效，需要再次居中标定。PID、舵机和电机设置有有效 EEPROM 记录后，不必每次重设。

## 四电感首次运行的附加核对

- 物理从左到右为 L、LM、RM、R；软件通道号为 1=L、2=R、3=LM、4=RM，不要照通道号当作空间顺序接线。
- 本次必须重做全部四路极值与车身居中标定；居中页显示 LM/RM 归一化强度，运行时 OLED 熄屏，四路信号通过蓝牙查看。
- ADC 是 1ms 整帧触发，PID 为 2ms。蓝牙新增第 40/41 列为扫描帧数、扫描跨周期次数；实车检查每 500ms 遥测间隔约增加 500 帧，跨周期数不持续增长。
- 高速舵机已确认 SPT5410LV，载波为 330Hz（周期约 3.03ms）；三值仍为 2us 单位，C=760 对应 1520us，L=840 对应 1680us，R=670 对应 1340us。核对新舵机的机械中值和限位后再运行。

速度环为右后轮单反馈，两电机共同 PWM，不做差速转向。速度 PID 要独立实车整定；速度目标与增益均掉电保存，不必每次重设。新版本完整蓝牙遥测为 52 列、500ms 一帧；详情见 SPEED_LOOP_GUIDE.md。
