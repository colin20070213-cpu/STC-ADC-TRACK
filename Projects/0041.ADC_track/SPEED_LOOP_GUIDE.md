# 单编码器速度闭环：只设一组 BASE/CURVE

## 菜单与数字含义

入口：主菜单 → 电机设置 → 速度设定。电机设置现在只有速度设定、左电机方向、右电机方向三个选项。原“动力限幅”的 BASE/CURVE 数字直接沿用为唯一速度目标，额外那组独立速度值不再使用。

- BASE：直线/小偏差目标，单位脉冲/秒，当前代码初值 2500。
- CURVE：大偏差/十字目标，单位脉冲/秒，当前代码初值 1400。
- 范围 0≤CURVE≤BASE≤4000；BASE=0 时不能发车。上下选择、右键编辑及切换 10/100 步长，中键保存、左键撤销/返回。
- 页面显示 pps（脉冲/秒）、NOW 实测速度、ENC/DIR 原始诊断及 PWM<=4000。静态设置页电机、舵机均关闭。

例如已有参数 2500/1400，升级后无需再填写此前的 1000/700。2500 表示每秒 2500 个 P04 脉冲，1400 表示每秒 1400 个脉冲；它们不再限制为25%/14% PWM。速度 PID 根据目标与反馈计算共同 PWM，统一绝对上限 TRACK_DUTY_MAX=4000（40%），该限制仍在驱动层复核。

## 控制与起步

```text
唯一 BASE/CURVE（脉冲/秒） → 按转向误差插值 → 速度 PID → 两电机共同 PWM（0～4000）
                                      ↑
                          右后轮 P04/TIM3 连续计数
```

ADC 和编码器快照均为 1ms，转向及速度 PID 均为 2ms。目标在下一次速度控制帧直接生效，PWM直接使用限幅后的 PID 结果；已删除目标速度慢爬升和 PWM 每毫秒增2的限制。零目标、手动停止、失线或故障处理不等待任何缓降。

内部保留原计数/10ms标度，输入目标 pps 除以100后计算误差，因此现有速度 PID 增益含义不变；串口与屏幕乘100后显示 pps。波形、增益和实际起步效果仍需实车验证，删除软件爬升不代表任何增益都能稳定。

速度 PID 在“PID调参 → 速度闭环调参”，支持0.01/0.10/1.00三档、中键掉电保存与第四项恢复代码初值。当前保留用户本地宏 Kp=500、Ki=0、Kd=0；已有有效 EEPROM 参数仍优先，不自动重置。转向 PID 与 C4 的参数仍独立。

## 保护

- 只有运行模式允许电机输出，右后轮一个反馈生成相同左右 PWM，禁止差速命令。
- 弱信号确认期间保留上次转向、共同动力只降不升，最大600 PWM；CURVE现在是速度单位，不再与PWM直接比较。
- 原普通弱信号250ms、四路近零120ms、ADC保护、20ms输出更新截止、手动停车保持。
- 1ms快照失败锁存到前台；快照超过2ms或测速间隔超过4ms、异常计数时停止。
- PWM≥1000且连续约1000ms无脉冲时 ENC STALL 停车。P52只显示原始电平，前进速度环用脉冲幅值，不声明AB四倍频或反向测速。

## 旧参数兼容

继续使用两个512B扇区，用户EEPROM至少1KB，SPD2总长80B，基础第31字节最后提交。offset20/22原动力数字迁为唯一 pps 目标；offset40/42原独立目标保留为 legacy_speed_base/legacy_speed_curve，仅用于兼容，不参与控制或启动校验。64～67写入PPS1单位标记并受扩展CRC保护；无标记旧SPD2及旧SPD1/v1/v2仍可读，保留原PID、舵机、方向和C4设置。下一次手动保存才升级，不在读取时擦写。

例如旧记录动力2500/1400、独立速度1000/700，新版有效目标是2500/1400 pps，旧1000/700不再生效。两套PID、舵机三值和C4权重不因此重置。

## 蓝牙

115200 / 8N1，只发四列：转向目标×1000、转向反馈×1000、速度目标pps、速度反馈pps。后一组直接按脉冲/秒看，例如0,50,2500,2300。无表头或其他参数列，运行及两种PID调参时上一帧发完即发最新值，其他模式静默，具体帧率受字符串长度、前台调度和链路吞吐影响。

## 使用步骤

烧录后核对唯一速度设定和实际PID、舵机方向/限位，再按原流程完成电感及居中标定即可运行。速度值和增益已掉电保存时不必每次重设；更改C4权重后仍需重新居中标定。原库文件和Keil分组全部保留。
