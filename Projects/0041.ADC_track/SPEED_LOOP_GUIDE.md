# 右后轮单编码器速度闭环

按用户说明的比赛限制，仅使用右后轮编码器。P04 接原库脉冲计数输入（TIM3），P52 沿用原库方向电平定义。两电机接收同一个动力值，转向由舵机完成；不设置左右独立速度环，不根据转向误差分配左右差速。驱动层在运行使能时还会拒绝不相等的左右动力命令。

## 控制链路与单位

```text
四路电感 → C4 融合、居中补偿 → 2ms 转向 PID → 舵机
                         ↓ 偏差/十字状态
                 基础/弯道目标速度插值
                         ↓
右后轮编码器 → TIM3 连续计数 → 1ms 快照 → 2ms 测速/速度 PID → 相同的左/右电机 PWM
```

ADC 整帧触发仍为 1ms，舵机 PWM 仍为 330Hz。编码器 TIM3 持续计数，TIM0 每 1ms 发布计数、P52 电平和采集时刻；前台每 2ms 复制最近快照，按两个控制时刻的实际间隔换算反馈并计算速度 PID。两次读取间的所有脉冲都保留在累计计数中，前台不必排队处理每个 1ms 快照。

速度单位为 **P04 计数/10ms**，不是 m/s、不是 PWM 百分比，也不是 AB 四倍频计数。比如 `BASE=20` 表示每 10ms 希望收到约 20 个 P04 计数。每圈计数和轮径未知，因此不自动换算物理车速。

P52 原始方向电平保留在速度设定页的 DIR 中；当前比赛只前进行驶，速度闭环调节的是脉冲频率幅值，不用周期采样 P52 去推导原始 AB 相位。该实现按原库接口使用，没有新增 AB 四倍频解码。右轮反馈不能代表左轮实测速度，打滑时也不能代表车身地面速度。

## 菜单入口

1. **速度设定**：BASE、CURVE 为基础/弯道目标计数，范围 0～1000，要求 CURVE≤BASE。右键进入编辑；上下修改；右键切换 1/10 步长；中键保存；左键撤销/退出。
2. **主菜单 → PID调参 → 速度闭环调参**：独立 Kp、Ki、Kd，支持 0.01/0.10 微调、中键保存及第四项“恢复PID初值”。此页面始终关闭电机和舵机，可手转右后轮观察 `V`。速度设定页同时显示原始累计 `ENC` 和 `DIR`，方便低速手转检查和测量一圈计数。
3. **动力限幅**：保留旧 BASE/CURVE PWM 参数，分别作为直线/弯道动力上限，绝对上限仍为 4000（40%）。它们不再是实测速度。
4. **左电机方向**、**右电机方向**：仍是接线/安装方向设置，不用于差速转向。

主菜单“PID调参”先进入选择层，包含“转向PID调参”和“速度闭环调参”；速度 PID 从原电机设置中移入此层。左键从调参页面返回选择层，再按左键返回主菜单；各层保留光标。转向调参允许舵机响应，速度调参关闭电机及舵机。修改速度 PID 不改转向三项参数。有效 Flash 设置优先。旧版 PWM 数字不被当作新速度目标迁移。

## 首次使用

新速度目标初值为 0，升级读取旧记录后同样为 0。需要先在速度设定中设置非零 BASE 并保存；否则开始运行显示 `NEED SPEED`。CURVE 可设为不大于 BASE 的较低目标；设为 0 表示最大偏差/十字时主动停动力。

先进入速度设定或速度 PID 页，手转右后轮，确认显示的轮速会随转动变化。未知每圈计数时不能指定一个通用的安全目标值，需从小目标低速试起。保持原本的四路电感标定、居中标定、机械方向与限位核对流程；运行时仍熄屏，使用蓝牙观察速度。

速度增益在 `USER/inc/track_config.h`：

```c
#define TRACK_SPEED_DEFAULT_KP 30.00f
#define TRACK_SPEED_DEFAULT_KI 30.00f
#define TRACK_SPEED_DEFAULT_KD  0.00f
```

这是可调初值，不能替代实车整定。可先把 Ki、Kd 设为 0，调 Kp 观察响应，再逐步加 Ki 消除稳态误差。电机、负载、编码器分辨率都会改变适合的增益。程序含目标速度上升斜率、PWM 加速限制、微分滤波及积分抗饱和；轮速低通与微分低通分别以 `TRACK_SPEED_FEEDBACK_TAU_MS=10`、`TRACK_SPEED_D_TAU_MS=30` 的时间常数和实际 dt 计算系数，避免缩短周期后固定滤波系数改变响应。停止或弱信号时清除速度积分。

## 停车与限制

- 失线确认期间仍保持原转向并限制公共 PWM，不允许速度积分将动力顶回去。信号恢复后重新渐进建立速度输出。
- 速度目标为 0 或动力上限为 0 时输出为 0。
- 稳定快照读取失败（即使中间失败后下一毫秒成功也会锁存）、快照超过 2ms、测速间隔超过 4ms 或计数明显异常时显示 `ENC ERROR` 并停止。
- 持续 PWM≥1000 且连续约 1000ms 没有脉冲，显示 `ENC STALL` 并停止。该提示可能是车轮堵转、编码器断线或调参后动力不足，需要实车区分。
- 原手动停车、ADC、失线和 20ms 输出截止保护保留。运行中任何停车均先停输出，再恢复 OLED 显示原因。

原库保留 `Encoder_Init/Encoder_Count_Read/Encoder_Clear`，新增 `Encoder_Snapshot`：高-低-高稳定读取，最多三次尝试，不清空正在计数的 TIM3。周期脉冲数使用 uint16_t 模差，正确处理 65535 回绕。原有累计接口也使用显式无符号回绕运算。

## Flash 兼容

仍使用原来的两个 512B 扇区，不增加 EEPROM 分配要求。每个槽前 32B 保留原 v2 基础记录，后 32B 加入 `SPD1` 速度扩展，包含目标和三项增益、CRC、与基础序号/CRC 的绑定。

擦写另一槽后先写所有数据和扩展，最后才写原第 31 字节有效标记，使基础与速度参数同次提交。兼容旧 v1/v2：后半为空时保留原方向、舵机、转向 PID 和 PWM，速度字段使用新初值。扩展损坏则拒绝该槽，尝试另一个有效槽。未改参数不会反复擦写。

## 蓝牙字段

仅在运行、转向 PID 调参、速度闭环调参时，每 **500ms** 发送一行四列数字 CSV；串口为 **115200 / 8N1**。顺序固定为：

```text
转向目标,转向反馈,速度目标,速度反馈\r\n
```

| 列 | 含义 | 标度 |
|---|---|---|
| 1 | 转向目标，默认 0 | 实际偏差单位 ×1000 |
| 2 | 电感融合、居中补偿后的实际位置反馈 | 实际偏差单位 ×1000，范围 -1000～1000 |
| 3 | 速度 PID 使用的目标，经过加速斜率限制 | 计数/10ms ×100 |
| 4 | 右后轮编码器滤波后的实际速度 | 计数/10ms ×100 |

例如 `0,50,2000,1850` 表示转向目标 0、反馈 0.050，速度目标 20、反馈 18.5 计数/10ms。转向反馈是电感推算的横向偏差，不是舵机角度；速度反馈采用实际参与速度 PID 的滤波测量。十字处理即使将控制误差暂时置零，也继续发送独立的位置反馈。

不发送表头、时间、模式、原始 ADC、增益、PWM、故障列或 `#CFG`；开机、菜单及保存操作没有额外串口帧。停车后退出运行，周期遥测停止，故障看 OLED。发送队列满时丢弃本帧，不等待、不影响 2ms 控制。串口只输出，不接受远程控制。

## 验证范围

主机测试直接链接原编码器库，覆盖计数回绕、不一致快照的有界重试和旧接口；闭环仿真覆盖量化脉冲、一阶电机负载变化、抗饱和、零目标、堵转停车；真实菜单测试覆盖新目标保存、速度 PID 与转向 PID 独立、运行相同左右 PWM 和编码器故障停车。Flash 升级与新速度保存均覆盖所有 65 个擦写中断点。另覆盖真实 TIM0 连续 20 个 1ms 快照、跨 65535 回绕、原子时间戳、失败锁存、过期拒绝、每 2ms 速度更新及 PID 二级菜单进出与光标记忆。实车转速、编码器信号、运行负载下 2ms 执行时长与闭环增益仍需实测。

## 1ms 采集的含义与型号资料

用户提供型号为 SQ15S03E210BSAS1。未检索到这一完整型号的官方数据手册；检索到的 [普地 S15S03E1/SDI 系列资料](https://2115200113.s21i.faiusr.com/61/ABUIABA9GAAgwLX6nAYolqm9_QM.pdf?v=1683813990) 仅为相关系列参考，不能据此确定本只编码器的 PPR、最大脉冲频率或 B/DIR 输出选项。程序不根据型号字符串猜分辨率，也不将相近型号频率作为“实测最大采集频率”。

1ms 是 MCU 保存累计计数的周期，不是编码器最高输出脉冲频率。脉冲由 TIM3 持续计数，P52 仍只作原始电平显示；前进速度环使用计数幅值，不声明支持 AB 四倍频或反向速度测量。实际输入脉冲频率、电平和 1ms 中断时序需上车确认。当前每 10ms 2000 次计数仅是软件异常阈值，不能当成此型号的额定上限。

2ms 窗口中每增加 1 个计数，未滤波速度会跳变 5 个“计数/10ms”单位，低速时出现零/非零交替是量化结果；低通能减小显示/控制抖动，但不能增加真实编码器分辨率。原速度单位与 Flash 参数保持兼容，升级后仍需重新检查速度 PID 响应，不要求重新输入舵机和方向设置。
