# 开始运行前检查与操作清单

本清单对应更换正常电磁放大板后的双电感固件。按键：上 P42、下 P46、左 P45、右 P41、中 P27；中键确认，左键返回或撤销。

## 一、首次烧录、修改硬件或调整参数后

1. 烧录 `MDK/Objects/Project_Template.hex`。STC-ISP 芯片选择 STC32G12K128，用户 EEPROM 至少分配 1KB，当前程序布局不要超过 64KB。希望后续重新烧录仍保留参数时，关闭下载器的擦除用户 EEPROM 选项。
2. 确认赛道电磁线正常通电；电感安装牢固，高度与实际运行一致。当前左电感 P13、右电感 P01，放大板输出须正确接入这两路 ADC。
3. 在“舵机设置”核对中值、左右限位、方向。当前代码默认中值 760、左限位 840、右限位 670；已有有效 EEPROM 参数优先。三个位置页面进入即输出对应舵机位置，电机关闭。方向设为反向时左右数值标签交换。
4. 在“电机设置”核对左右电机方向及速度。默认 BASE=1000（10%）、CURVE=600（6%），必须满足 `0 ≤ CURVE ≤ BASE ≤ 4000`。提高上限不会自动提高已保存动力，需要在速度页调整并中键保存。方向设置页不会让电机试转；需完成下文标定后架空短时运行，验证两轮前进方向，左键或中键停止，再根据结果调整方向。
5. 核对 PID 页的实际参数。代码当前初值 Kp=200.00、Ki=0.00、Kd=0.15，允许范围分别为 0～500、0～20、0～20。已有有效 EEPROM 参数仍优先；需要使用代码初值时，选择“恢复PID初值”，第一次中键预览，第二次中键保存，确认 `SAVED OK`。
6. 修改任一需要掉电保存的设置后，按中键确认，看到 `SAVED OK`。失败时按屏幕错误阶段排查，不能将预览数值当作已掉电保存的值。

## 二、每次上电后必须按顺序执行

### 1. 电感标定

- 进入“标定设置 → 电感标定”，进入即开始采集。
- 保持安装高度不变，手动移动小车，使左右每个电感都经历弱信号和强信号位置，观察 `N/m/M`。
- 每路采样至少 100 帧，每路 `M-m ≥ 100`，且 `M < 4090`；实际应充分扫过信号范围，不能只等待采样计数增加。
- 按中键校验并确认；成功后自动回到标定菜单。左键退出为取消，右键清空重新采集。

### 2. 车身居中标定

- 将小车放到直线赛道中央，车身纵向对齐赛道，保持静止，进入“标定设置 → 居中标定”。
- 按中键开始采集 200 帧，约 1 秒；此时电机及舵机输出关闭。
- 归一化 L/R 每路至少为 100，总和不低于失线阈值（当前代码默认 40）；E 绝对值不超过 300，整次采集 E 的最大值与最小值之差不超过 60。
- 显示 `READY: OK TO SAVE` 后，再按中键，看到 `CENTER SAVED (RAM)`，然后按左键返回菜单。
- `SIGNAL TOO WEAK` 为信号强度不足；`UNSTABLE: RETRY` 为采集期间波动过大；`OFF CENTER: REALIGN` 为偏差过大。调整摆放或信号后重新采集，失败不会生成新的有效居中参考。

### 3. 核对转向并选择开始运行

- 首次整定或改过方向时，在 PID 调参模式下观察电感偏差与舵机响应，确认舵机向使车身回归赛道的方向纠偏；该模式电机始终关闭。
- 确认速度、机械限位及电机方向合适后，将小车放在有效赛道信号范围内，主菜单选择“开始运行”，按中键发车。
- 运行中左键或中键立即停止。弱信号确认期间保持原转向，动力不超过原值、CURVE、600 的最小值；普通弱信号约 100ms、两路连续近零约 50ms 后停车。使用当前代码初值 40 时，总和恢复到 90 时可在确认期内恢复循迹。ADC 故障或控制超时仍直接停止；已经停车后需手动再次发车。

## 三、发车提示对应什么前置条件

| 提示 | 含义与操作 |
|---|---|
| NEED CAL | 本次上电尚未成功确认电感标定，先完成第 1 步 |
| NEED CENTER / NEED CENT | 尚未成功确认居中参考，先完成第 2 步 |
| PARAM ERR / FLASH PARAM ERROR | 控制参数不合法；保存会检查整套参数。核对 PID、舵机、动力关系及方向；失线总强度合法范围为 1～500，当前初值 40 可正常保存 |
| MATH ERROR | 上电整数计算自检失败，先排查固件及运行环境 |
| LOST | 弱信号持续约 100ms，或两路连续近零约 50ms，已停车；重新摆放到有效赛道信号区域后再启动 |

先前一处 `PARAM ERR` 原因是 Kp=400.00 超过当时允许上限 200.00。当前上限为 500.00，代码初值为用户当前设置的 200.00；上电会检查参数，有效 EEPROM 记录仍优先。

电感极值和车身居中参考只存在 RAM：每次断电重启均须重新完成两项标定。成功重做电感标定也会使旧居中参考失效，需要再次居中标定。PID、舵机和电机设置有有效 EEPROM 记录后，不必每次重设。
